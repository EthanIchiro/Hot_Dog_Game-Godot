# 🌭 Hot Dog Cannon v8.0

## The world's most advanced hot dog transportation technology.

*(Probably.)*

Welcome to **Hot Dog Cannon**, a game where you must protect a delicious hot dog from a hungry enemy using the most questionable invention ever created:

# 💥 THE HOT DOG CANNON 💥

Your mission:

1. Move around.
2. Protect the hot dog.
3. Shoot the enemy.
4. Accidentally shoot the hot dog.
5. Accidentally shoot yourself.
6. Watch everything go horribly wrong.

Simple.

# 🎮 Controls

| Key | Action |
| --- | --- |
| WASD / Arrow Keys | Move yourself, the hot dog, and somehow your bullets |
| Space | Fire the cannon |
| R | Restart the chaos |
| Enter | View achievements |

# 🐕 Hot Dog Storm™

Sometimes your hot dog hits the cannon.

The cannon responds logically:

> "MORE DOGS!!!"

Then the sky fills with bonus hot dogs.

This is normal engineering.

# 👾 The 404 Event

There is a tiny chance the enemy says:

> "404 Error: Food not dected"

and completely gives up.

The enemy has discovered the true power of bugs.
